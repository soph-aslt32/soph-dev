# /etc/dcs/firewall-domains.txt（dcs-image。root 所有）— ファイアウォールの固定の許可リスト（DESIGN.md の 6.6。D55）
# 1 行に 1 つのドメイン。# の行はコメント。ドメインのすぐ上の # の行が、そのドメインの用途になる
# （引けなかったときの [WARN] に出す。空の行で区切ると、用途は引き継がない）。
# 引けないドメインは [WARN] を出して飛ばす。DNS から答えが無いときは、閉じた状態で失敗する（D54）。
# 起動のときに 1 回引いた IP だけを許すので、引くたびに違う IP を返すドメイン（Google の共用の入り口など）は書かない（届かない。D55）。
# github.com・api.github.com などの GitHub の本体は、ここではなく https://api.github.com/meta の IP の範囲で許す。
# GitHub のドメインのうち、その範囲の外のものと、用途をはっきりさせておきたいものだけを、ここに書く。
# 開発環境で必ず使うもの（Claude Code・VS Code・GitHub・Rust・Python）は、ここに書く。それ以外は、開発環境ごとの allowed_domains に書く。
# 次の公式のページが変わったら、ここを直す: Claude Code の network-config、VS Code の network と Remote の FAQ、uv の環境変数の一覧。
